LibRing

Smart Ring Research Demonstrations

This page lists a few research demos illustrating possibilities with a reverse engineered smart ring available online (examples: amazon, aliexpress). More information can be found in the repository.

👋 Gesture Recognition

Interactive demonstration of real-time gesture recognition using the LibRing device. Classifies movements on the fly.

✨ Sleep Recognition

Monitor and analyze movements and sleep stages. Demonstrates classification of resting states.

📸 Camera Controller

Use the ring to remotely control the camera. Snap pictures with the touch sensor on the ring.

🎵 Web MIDI Interface

Control MIDI instruments with the ring's accelerometer, using X, Y, Z data to send CC for real time effect modulations.

↝ Perlin Noise Visualizer

An interactive visualizer manipulating Perlin noise fields in real-time using accelerometer data from the ring.
